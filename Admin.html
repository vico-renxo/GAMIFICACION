🖼️ Gestión de Imágenes
Las imágenes se almacenan en Google Drive. Convierte el enlace compartido en URL directa.

📋 Pasos para agregar una imagen

  1. Abre Google Drive (drive.google.com) y sube tu imagen
  2. Click derecho → Compartir → Cualquiera con el enlace → Copiar
  3. El enlace es: https://drive.google.com/file/d/FILE_ID/view
  4. Pega abajo en el conversor para obtener la URL directa
  5. Copia la URL directa y pégala en el campo "Imagen URL" del módulo
