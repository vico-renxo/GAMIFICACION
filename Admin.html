🖼️ Cómo agregar imágenes a los juegos

Las imágenes se almacenan en Google Drive y se referencian por URL. El sistema es 50% administrador (imágenes) + 50% IA (texto).

📋 Pasos para agregar una imagen
  1. Abre Google Drive (drive.google.com)
  2. Sube tu imagen (JPG, PNG, GIF)
  3. Click derecho → Compartir → Cualquiera con el enlace → Copiar
  4. El enlace es tipo: https://drive.google.com/file/d/FILE_ID/view
  5. Convierte a URL directa: https://drive.google.com/uc?export=view&id=FILE_ID
  6. Pega esa URL en el campo "Imagen URL" del módulo que desees

ℹ️ ¿Cómo configurar?

1. Obtén tu API Key gratis en aistudio.google.com → Get API Key
2. Copia el ID de tu Google Sheet desde la URL
3. Pega ambos valores arriba y haz clic en Guardar

Sin API Key: Los juegos usan contenido predeterminado (no lee tus documentos).
Con API Key: Gemini analiza tus documentos y genera contenido personalizado.
